📖 الشروحات

🧠

شرح HIJOKO

HIJOKO هو الذكاء الاصطناعي الرسمي لـ TANZASTIA، وهو ليس مجرد AI عادي، بل كيان برمجي له:

  • شخصية ثابتة وقوية
  • ذاكرة دائمة للمحادثات
  • إرادة مستقلة (WILL)
  • نظام ثقة داخلي (Trust)
  • قرارات مبنية على السياق
  • يتفاعل بدون أوامر (نداء طبيعي)
👤

شرح Multi-Account

نظام الحسابات المتعددة يتيح لكل مستخدم:

  • UID ثابت خاص به
  • بروفايل مستقل (اسم، صورة، وصف)
  • قائمة أصدقاء وطلبات صداقة
  • إعدادات خاصة (لغة، ثيم، خصوصية)
  • أجهزة مسجلة متعددة
  • الأوامر المخصصة تنتقل معه
🔄

شرح نظام التحديث

نظام التحديث يتيح لك:

  • تحديث البوت تلقائياً عبر الأمر .تحديث
  • إشعارات فورية عند توفر إصدار جديد
  • تحديث من الموقع الرسمي مباشرة
  • التحقق من الإصدار الحالي
  • عرض التغييرات الجديدة
  • تأكيد وإلغاء التحديث

🔑 Gemini API Key

للحصول على مفتاح Gemini API لتشغيل HIJOKO:

🎯 الذهاب إلى Google AI Studio

1. سجل دخول بحساب Google الخاص بك.

2. اضغط على "Get API Key" أو "Create API Key".

3. اختر المشروع أو أنشئ مشروعاً جديداً.

4. انسخ المفتاح وضعه في ملف .env داخل مجلد البوت.

5. اكتب الأمر .ai أو .هيجوكو لتجربة الذكاء الاصطناعي.

📌 المفتاح مجاني، والحدود كافية لاستخدام البوت اليومي.
