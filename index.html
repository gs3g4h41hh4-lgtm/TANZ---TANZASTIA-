⚙️ الأنظمة

🧠

HIJOKO

الذكاء الاصطناعي الرسمي لـ TANZASTIA، وليس مجرد بوت ردود. HIJOKO نظام متكامل بشخصية وذاكرة وإرادة.

  • شخصية ثابتة وقوية
  • ذاكرة دائمة للمحادثات
  • إرادة مستقلة (WILL)
  • نظام ثقة داخلي (Trust)
  • تفاعل بدون أوامر عند الحاجة
👤

Multi-Account

نظام الحسابات المتعددة يتيح لكل مستخدم حسابًا مستقلًا ببياناته الخاصة.

  • UID ثابت لكل حساب
  • Profile مستقل (اسم، صورة، وصف)
  • Friends & Requests
  • Settings خاصة
  • Sessions & Devices
🔄

Update System

نظام تحديث متكامل يعلمك بوجود إصدار جديد ويقوم بتحديث TANZASTIA بسلاسة.

  • إشعار عند توفر تحديث
  • التحقق من الإصدار الحالي
  • عرض التغييرات (Changelog)
  • تأكيد أو إلغاء التحديث

🔑 Gemini API Key

للحصول على مفتاح Gemini API لتشغيل HIJOKO:

🎯 الذهاب إلى Google AI Studio

1. سجل دخول بحساب Google.

2. اضغط على "Get API Key".

3. اختر مشروعًا أو أنشئ واحدًا جديدًا.

4. انسخ الـ API Key.

5. ضعه في ملف .env داخل مجلد TANZASTIA.

6. جرب الأمر .ai أو .هيجوكو.

📌 المفتاح مجاني، والحدود كافية للاستخدام اليومي.
